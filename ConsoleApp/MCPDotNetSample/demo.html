User Management - Data Filter Overview 

1. Select "Data Filter" in navigation bar.

Click "User Management" to access this option.


2. "Data Filter".

Create a Data Filter and assign it to a particular user so that only Filtered Data are shown to a Particular User.


3. "Filter" options.

Filer through the list of Data Filter using options like Timeline & Searching through Data Filter Name.

Click on "Tick Mark" icon to filter the data accordingly.

Click on "Refresh" icon to remove the filter.


4. Create new Data Filter.

Click on "+Add Data Filter" to create a new data filter.


5. Enter Basic Details.

Give your Data Filter a Name and small description from here. Click "Save" to finalize the details and start creating Data Filters conditions.


6. "Add Module"

Create on "Add Module" to add a module and create filter accordingly.


7. "Select Module".

Select a Module like Customer or IB. According to set Module the Filter options would change & for that module, the filter would be applied.


8. "Filter".

Select the filter option from here. In this particular case, we are selecting Country.


9. "Criteria".

Select the criteria that would be applied on filter to satisfy the condition.

In this particular case, we are selecting "In".


10. "Value".

Type a Value and add them into here. In this case we are adding "India" & "Australia" as the value.


11. Filter Condition Set.

The Filter conditions together reads as follows:

The data filter would filter those Clients whose country is India & Australia & show their data only to the users.


12. Add another Condition.

Click on "+" icon to add another "AND" condition.,


13. Select Another "AND" Condition.

Create another condition with "AND" condition.

What this means is that both the conditions should be satisfied in order for the data to be filtered.


14. "Add New Filter".

Create a New Filter Condition with "OR" condition.

What that means is that either this condition or the previous condition should be satisfied in order for the data to be filtered.


15. New Filter.

We have added another Filter with "AND" condition.

In this case the customers whose country is Albania & their risk classification is Medium, only that data would be filtered.

This is a OR filter which means that either this filter condition or the previous filter condition should satisfy in order for the data to be classified here.


16. Click "Save" to finalize your settings and proceed forward.



17. "Module" Space.

The following Space contains information of a Module like Name, Request date, Created By & Last Updated on.


18. "Action" Column.

Click on "Eye View" icon present under the Action column to view and edit the module.


19. Delete a Module.

Click on "Three Dot" icon present under action column to delete a module.


20. "Data Filter" Space.

This Space contains information related to a Data filter like ID, Data Filter Name, Created on date, Created By & when was it last updated on.


21. "No. Of Users".

The particular data filter is assigned to how many users are shown here.

You can manually assign users by clicking on the No. of users.


22. Assign Data Filter to Users.

Select the User you want to assign the specific data filer to from here.

Click "Save" to finalize your settings and successfully assign them the Data Filter.


23. "Action" Column.

Select "Eye View" icon present under Action column to view and edit any Data filter.


24. Delete a Data Filter.

Click on "Three Dot" icon present under Action Column to Delete a Data Filter.


25. "Audit Log".

Any action taken by anyone in the CRM Regarding Data Filter would be logged or registered here and can be viewed here.


26. "Sub-Category".

Filter through the list of Logs using this option.


27. "Action".

Based on the actions taken, you can filter through the list of Logs to find a specific one using this option. They are of 3 types:

1) Inserted: When somebody has inserted a new value.

2) Updated: When somebody has change the status of particular value.

3) Deleted: When somebody has deleted a value.


28. "Timeline."

You can select the time duration for which you want to see the Audit Log through here.


29. Filter Data.

Click on Tick Mark icon to Filter the Data accordingly.


30. Remove Filter.

Click on Refresh icon to remove the Filter or reset the data.


31. "Logs Details".

Here you can see the details of a particular Log.

For example here, the "Title" View Filter Name & Description, in them new value were inserted.
